怎么玩

      
    
        
  • 目标：把对手总部 20 点防御打到 0。
    • 
        
  • 指挥点：每回合 +1，上限 12，回合开始回满；卡面左上角数字就是花费。牌库抽空后每抽一张受递增疲劳伤害。
    • 
        
  • 前线（双方共抢的一条线）：单位先进入自己的支援阵线；移动到前线会花掉行动并支付行动花费。
          前线每方最多 5 个，双方可以同时站在线上 —— 你在前线有人、对手没有 = 你控制前线（面板会显示）。
          只有前线的单位能攻击敌方总部（对方有固守单位时必须先解决固守）。
    • 
        
  • 攻击范围：支援阵线里的步兵/坦克只能打敌方前线；炮兵、战斗机、轰炸机、巡地舰、巡航舰可以跨阵线攻击任意战线的目标，
          其中火炮 / 轰炸机 / 太空单位（巡地舰·巡航舰·太空战机）无视固守（战斗机仍受固守限制）。太空单位攻打陆军不会受到反击伤害。
    • 
        
  • 兵种怎么认：看卡面「攻击 / 防御」中间的单位图标 —— 士兵=步兵、坦克轮廓=坦克、
          长炮管=火炮、飞机=战斗机/轰炸机、三角形=太空战机、圆角车体+横带=巡地舰、箭形舰体=巡航舰。
          带两个攻击数字的单位一定是巡航舰。
    • 
        
  • 反击规则：通常互伤，但下列情况不反击 —— 攻方是炮兵；攻方是轰炸机且目标不是战斗机；
          攻方带冲击（首次攻击）；守方是炮兵；守方是轰炸机而攻方不是战斗机。
          轰炸机打战斗机、战斗机打轰炸机时正常互相伤害。
    • 
        
  • 固守/守护：只保护同一阵线上的目标 —— 前线固守挡前线目标，支援线固守挡支援线目标；总部算支援阵线目标，所以只有敌方支援线的固守才保护总部。
    • 
        
  • 行动花费：卡面花费格右下角的小数字，攻击与移动都要付；坦克可以同回合"先移动再攻击"（付两次），闪击只取消"部署当回合不能动"的限制。
    • 
        
  • 操作：把卡从手牌拖到支援阵线即可出牌；拖动场上单位到另一条阵线移动，拖到敌方单位或总部攻击；普通点击只查看详情；Esc 取消，空格 结束回合。
    • 
          金 = 同名最多 1 张
          银 = 2 张
          铜 = 3 张
          铁 = 4 张
          无标志 = 不能放进卡组，只能由其他卡牌产生（开发 / 加入手牌 / 召唤）
        
        
  • 词条：闪击（部署当回合可动）、固守（必须先打它）、烟幕（攻击前不可被指定，攻击或移动后解除）、
          伏击（每回合首次被攻击时先手反击）、动员（上前线触发）、狂怒/奋战（每回合攻击两次）、
          亡计（死亡触发）、老兵（达成条件升级）、冲击（首次攻击不会受到反击伤害，攻击后失去）、
          游击、流亡、重甲N、强磁护盾、硬铝弹等。鼠标悬停任意卡牌可看词条说明。
    • 
        
  • 设置：右侧面板可以选谁先手、以及 AI 难度。这套 DIY 卡池节奏极快，先手与 1 点指挥点的差别就能决定胜负，觉得太简单就让 AI 先手或开"困难"。

局域网联机对战

      
对战页右侧顶部有两个模式按钮：单机 · 对 AI 和 联机 · 局域网。
      
    
        
  1. 建房方：双击 启动游戏.cmd 起服务（窗口里会打印你的局域网地址），
          切到「联机 · 局域网」→ 填昵称 → 点 建房，把地址和 4 位房间码发给对方。
    2. 
        
  2. 加入方：用浏览器打开那个地址 → 「联机 · 局域网」→ 填房间码 → 加入。
    3. 
        
  3. 连上后自动做 DIY 数据对等：两边卡池逐张比指纹，一方独有的卡会把它的
          同名但内容不同的卡按房主版本统一；对不齐就不让开局，并写清还差什么。
    4. 
        
  4. 勾选「同步卡图」会顺便把对方那边你缺的卡图传过来（首次联机稍慢，之后不用再传）。
    5. 
        
  5. 双方各选一副卡组 → 房主点 开始对局。先后手永远随机（由开局种子决定，
          两边算出来必然一致，不提供人工挑先手）。换牌阶段要两边都确认才开局。
    6. 
        
  6. 对局中每方只在自己的回合操作。对手出牌 / 攻击 / 移动你都会看到和他一样的动画，
        
  7. 联机时不显示战报：战报是双方共用的一份，里面有「情报看到了对手哪张手牌」
      

      
技术口径：两边各跑一份确定性引擎（随机数走种子），只同步「动作 + 每一步选择的答案」，
        卡池差异在开局前就被拉平 —— 这是"双方 DIY 数据不对等"的根治办法。

      
导入自己的卡

      
    
        
  1. 把卡图 PNG 与 cards.json 放进一个文件夹，点「选择文件夹 / 文件」。
    2. 
        
  2. 没有 cards.json 时，游戏会先建出只有卡图与文件名的卡，点开它填数值与效果文本，再点「自动解析效果」——常见中文句式（抽牌/伤害/消灭/增益/压制/洗入卡组/部署：/亡计：…）会自动生成可执行效果。
    3. 
        
  3. 解析完整时结果才会写进效果 DSL。遇到未识别内容，编辑器会显示警告并保留当前 DSL；修改原文或手写 DSL 后再保存。卡面原文旁的「解析规范」说明了句式与 DSL 规则。
    4. 
        
  4. cards.json 字段：id, name, set, cardType(unit|order), unitType, cost, attack, defense, opCost, keywords[], text, effects[]。
    5.
